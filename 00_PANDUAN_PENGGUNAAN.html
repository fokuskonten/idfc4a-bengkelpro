Software Manajemen Kasir, Transaksi Sparepart, Jasa Servis & Antrean Bengkel

* Anda dapat mengubah username dan sandi setelah berhasil masuk melalui menu Manajemen Pengguna.

2. Cara Menjalankan Aplikasi Setiap Hari

  1. Langkah 1: Dobel-klik ikon BengkelPro di layar Desktop Anda.
  2. Langkah 2: Sistem otomatis menyalakan mesin server di latar belakang secara siluman (tanpa jendela hitam konsol).
  3. Langkah 3: Jendela aplikasi BengkelPro akan otomatis terbuka di layar dan siap digunakan untuk melayani pelanggan.
  4. Langkah 4: Setelah selesai bekerja, Anda cukup menutup jendela browser seperti biasa. Data tersimpan permanen di komputer Anda.

3. Fitur Utama BengkelPro

  • Master Data Barang & Sparepart: Input stok oli, ban, onderdil, harga beli, dan harga jual bengkel.
  • Kategori Jasa Servis: Kelola tarif tune-up, servis berkala, ganti oli, turun mesin, dan ongkos teknisi/mekanik.
  • Kasir Transaksi Terpadu: Gabungkan transaksi pembelian sparepart dan biaya jasa servis dalam satu invoice nota.
  • Laporan Keuangan & Riwayat: Rekap pendapatan harian, laba penjualan sparepart, dan rekap servis bulanan.
  • Cetak Struk Nota: Dukungan cetak struk nota belanja untuk pelanggan bengkel.

4. Pemeliharaan & Cadangan Data (Backup)

  • Penyimpanan Data: Seluruh basis data bengkel Anda tersimpan secara lokal dan aman di dalam folder Desktop\BengkelPro\mysql\data\.
  • Master Cadangan: Berkas BengkelPro_Master_Cadangan.zip tersedia di dalam folder proyek sebagai arsip cadangan bersih.
  • Pencopotan Bersih: Jika ingin membersihkan instalasi, jalankan Uninstall_BengkelPro.bat di dalam folder proyek.
