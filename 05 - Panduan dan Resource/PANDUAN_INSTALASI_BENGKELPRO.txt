PERSYARATAN LINGKUNGAN SERVER (LOCAL / CLOUD):
1. Web Server Lokal yang Direkomendasikan:
   - Laragon Full (Sangat Direkomendasikan): Apache / Nginx + MariaDB/MySQL + PHP.
   - XAMPP v8.1 / v8.2 atau Docker Container.
2. Basis Data:
   - MySQL 5.7+ / MariaDB 10.4+.
   - Import file database SQL yang tersedia di folder paket instalasi.

CARA INSTALASI CEPAT 3 LANGKAH:
1. Pindahkan Source Code:
   - Letakkan folder aplikasi ke dalam direktori web server Anda (contoh: C:\laragon\www\ atau C:\xampp\htdocs\).
2. Impor Basis Data:
   - Buka phpMyAdmin (http://localhost/phpmyadmin).
   - Buat database baru sesuai petunjuk file konfigurasi.
   - Impor file database (.sql) bawaan paket ini sampai selesai (Zero Error).
3. Konfigurasi Koneksi & Jalankan:
   - Buka file koneksi database (.env atau config.php / database.php).
   - Sesuaikan username dan password database lokal Anda.
   - Buka browser dan akses alamat aplikasi Anda di http://localhost/[nama_folder].
   - Atau klik ganda "buka_aplikasi.vbs" / "BUKA_APLIKASI.bat" untuk peluncur instan.
